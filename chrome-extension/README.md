# 述策助手

这是一个独立的 Manifest V3 Chrome 插件，用于在已经登录的 X 页面中查看和处理 Ediora 草稿，并辅助确认 X 原生安排表的最后一次时间选择。当前版本把指挥台放在浏览器 Side Panel，不提供 DevTools 发布命令或 `window.Shuce` 接口。

插件不读取 Cookie、Token 或其他登录凭据。草稿通过 service worker 访问本机 API，正文只保存在当前页面内存；安排表记忆保存在 X 页面自己的 `localStorage` 中，不写入后端或扩展存储。

## 加载插件

1. 打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`chrome-extension/`。
5. 打开 X；修改源码后先点击插件卡片上的“重新加载”，再刷新 X 页面。

插件只匹配 `https://x.com/*` 和 `https://twitter.com/*`。

## 浏览器 Side Panel 指挥台

打开 X 后，点击浏览器工具栏里的「述策发布指挥台」图标，右侧会出现指挥台。首次使用必须点击工具栏图标，插件不会自动弹出。边栏只在 `x.com` / `twitter.com` 可用；离开这些页面后边栏会关闭。回到 X 后如未自动恢复，再点一次工具栏图标即可。X 时间线上不再出现悬浮入口。

指挥台默认读取 `http://localhost:8000/api/write/drafts`，只展示 `status=ready` 的草稿，但保留文章、X、公众号和其他 `draft_type`。

- 列表和预览可以在上下布局和左右布局之间切换；选择会记在扩展存储里，下次打开边栏沿用。
- 上下布局时列表在上、预览在下；左右布局时列表在左、预览在右。
- 可以搜索标题/正文，并按内容类型筛选。
- 选中草稿后会渲染 Markdown，标题、列表、链接和正文中的图片都会显示；原始草稿内容不会被修改。
- 点击“复制 Markdown”会把完整原始 Markdown 放入纯文本剪贴板；浏览器支持富文本剪贴板时，会额外带上渲染格式和可访问的图片。
- 点击“发布并下一条”会把当前 `status=ready` 草稿更新为 `status=published`，然后自动选中当前结果中的下一条；最后一条不会循环回第一条。
- 这个按钮只负责标记系统状态，不执行 X 的实际发布动作；请先在 X 完成发布或安排，再点击按钮确认。
- 发布失败时当前草稿会保持选中，可以直接重试。
- 点击刷新重新读取列表；列表和正文可以独立滚动。
- 头部显示 `上次安排：YYYY-MM-DD HH:mm`；没有有效记录时显示“未记录”。
- 勾选“自动填入发布时间”后，安排表每次重新打开都会以“上次确认时间”为基准加 1 小时，并把分钟随机设置为 `00–15`；首次没有记录时使用当前时间加 1 小时。勾选状态会保存在当前 X 页面的本地存储中。
- 自动填入不会立即更新“上次安排”；只有点击 X 原生确认按钮后，实际填写的时间才会成为下一次的基准。取消勾选后恢复只还原上次时间的行为。
- 设置中可以填写任意 HTTP/HTTPS API 地址。首次保存某个域名时，Chrome 会请求该域名的访问权限；授权后会重新读取草稿。“恢复默认”返回 localhost 地址。
- API 不可用时，面板会显示可重试的行内错误，不影响 X 页面继续使用。

插件按 API 域名申请访问权限，不会读取 Cookie、Token 或其他登录凭据。Markdown 图片仍只从当前 API 地址下的 `/uploads/` 路径读取。

## 安排表最后选择记忆

插件继续兼容以下页面本地存储键：

```text
x_schedule_last_selection_v3
```

安排表打开后，插件会恢复上次有效选择。只有点击 X 安排表的确定按钮（`data-testid="scheduledConfirmationPrimaryAction"`）时，插件才会读取当前日期和时间并保存；调整下拉框或输入框的过程中不会写入。内部安排表驱动只负责设置控件，最终由确定按钮 click 统一触发保存。

旧版五字段数据仍然有效：`month`、`day`、`year`、`hour`、`minute`。六字段数据可额外包含 `period`（`AM` 或 `PM`）。

## 当前边界

- 当前指挥台不执行 X 的实际发布，不提供 DevTools/控制台调用入口，也不会创建 `window.Shuce`；“发布并下一条”只更新草稿状态。
- 当前不执行线程、图片、视频、投票、X Articles 或多条发布队列的 X 发布动作；Markdown 图片可在插件预览和富文本复制中显示。
- X 页面 DOM 变化、账号权限、Premium/安排表资格和产品策略都可能导致安排表控件无法识别。
- 修改插件源码后，需要在 `chrome://extensions/` 重新加载插件并刷新 X 页面。
