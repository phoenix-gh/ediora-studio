# 提示词资产左右布局与图片预览设计

## 目标

在提示词管理页的生成历史中，将提示词与对应的图片/视频改为左右布局；媒体保持完整比例显示，并提供可缩放的完整图片预览。

## 范围

- 修改 `wemedia-studio/app/assets/PromptAssetWorkspace.tsx` 的生成历史展示。
- 增加生成历史媒体预览交互：图片点击打开对话框，滚轮缩放，放大后拖动平移，支持重置与关闭。
- 更新 `wemedia-studio/app/assets/PromptAssetWorkspace.test.tsx`，覆盖布局、完整显示和预览交互。
- 不修改数据库、API 和 `PromptGeneration` 数据结构。

## 交互设计

### 生成历史卡片

每条生成历史使用响应式左右布局：

- 左侧为“当前提示词”区域，保留提示词正文中的换行，正文过长时在卡片内部滚动。
- 右侧为媒体区域，图片和视频使用 `object-contain`，不使用固定裁切比例，不截断媒体内容。
- 窄屏自动堆叠为上下布局，避免左右区域挤压。
- 生成中、排队中和失败状态仍保留左侧提示词，右侧显示对应状态。
- 模型、时间和删除操作保留在媒体信息区域。

生成历史接口只返回 `prompt_asset_id`，没有每次生成的提示词快照。因此左侧明确标记为“当前提示词”，展示当前提示词资产正文，不伪造历史版本。

### 图片预览

- 点击图片或通过键盘聚焦后按 Enter/Space，打开对话框。
- 对话框内默认将整张图片适配到可视区域，保持原始宽高比。
- 鼠标滚轮向上放大、向下缩小，缩放范围为 1x 到 4x。
- 缩放后可通过指针拖动查看图片其他区域；未放大时不产生无意义的位移。
- 提供缩放比例/重置操作；Esc、关闭按钮和点击对话框关闭区域退出预览。
- 预览区域遵循项目浅色/深色主题，图片不改变原始颜色。

视频继续在卡片中使用原生 controls 和完整比例展示；本次图片预览不扩展为视频缩放器。

## 实现边界

- 预览状态只存在于客户端组件，不写入 URL、localStorage 或数据库。
- 缩放和平移使用 React 状态与指针事件，不注册未清理的全局监听器。
- 图片按钮提供可读的 `aria-label`，预览对话框提供标题和关闭语义。
- 不改变生成、补录、删除、轮询和保存逻辑。

## 测试设计

在 `PromptAssetWorkspace.test.tsx` 中增加：

1. 生成历史同时渲染“当前提示词”和图片，图片使用完整显示样式而非裁切样式。
2. 点击图片打开预览对话框，预览显示完整图片。
3. 对预览区域触发滚轮事件后，缩放变换发生；点击重置后恢复 1x。
4. 现有图片生成、视频补录和历史加载测试继续通过。

验证范围为提示词管理组件测试、必要的 TypeScript 检查和 `git diff --check`，不运行全量测试。
