# 创作资产库设计

## 目标

移除旧的文本素材库及其 X 采集链路，保留草稿封面上传；新增独立的创作资产库，用于保存和复用文章、图片、视频。

## 范围

- 删除旧 `/materials` 页面、客户端 API、后端路由、`RefMaterial` / `RefCollectRule` / `RefSeen` 数据模型、相关计划任务、配置项、仪表盘项和 Chat 素材检索。
- 新增 `/assets` 页面和 `/api/assets` API。资产记录使用一个 `CreativeAsset` 表，字段包括类型（`article`、`image`、`video`）、标题、正文或文件 URL、媒体类型、原始文件名、标签、来源、创建/更新时间。
- 文章资产可创建 Markdown 内容；图片与视频资产可上传。图片、视频都使用现有 `backend/uploads` 静态文件存储；封面上传和草稿内图片不改变。
- 草稿编辑器的资源弹窗增加“创作资产”入口：文章资产插入 Markdown，图片资产插入图片 Markdown，视频资产插入链接。原有来源、草稿图片和 AI 生图能力保持不变。

## 不做

- 不迁移旧素材库数据到新资产库。
- 不实现文件夹、版本、权限、多用户、自动同步或媒体转码。
- 不删除已上传文件、草稿图片、文章草稿及外部信息源。

## 验收

- 导航与 API 不再暴露旧素材库。
- 数据库初始化会删除旧素材库表和相关调度配置不再生效。
- 可创建、浏览、搜索、删除文章/图片/视频资产。
- 草稿可从资产库插入文章、图片或视频引用。
