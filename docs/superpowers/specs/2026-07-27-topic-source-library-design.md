# 主题来源素材库

## 目标

在创作资产文章目录中保存主题相关的原始内容，使采集记录可清理而素材仍可用于每日二次创作。

## 模型

文章素材仅保存 `content` 和可选 `url`，目录即主题（例如“副业搞钱”）。不保存作者和发布时间。

## 入库与去重

- 指定 X 账号内容先按主题关键词初筛，再由 AI 判断是否入库。
- 有 URL 时按规范化 URL 去重；无 URL 时按规范化内容 SHA-256 去重。
- 素材库拥有内容快照，不依赖 X 采集表；重复命中不创建副本。

## 手动管理

文章素材支持新增、编辑、删除。URL 可空；更新内容或 URL 时重新执行去重校验。

## 每日创作

每天从指定主题目录挑选 10 条未使用素材作为二次创作候选；原始素材不被改写。
