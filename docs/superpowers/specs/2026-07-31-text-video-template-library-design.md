# 文字视频模板库设计

## 目标

在现有 `audio + segments + templateProps` 渲染契约上，把单一
`tech-text-v1` 扩展为 5 套可选择、可设置、可预览并可导出 MP4 的模板。
模板是同一个 Remotion 工程内的 Composition，不为每个作品复制工程。

## 调研结论

- Remotion 官方将模板定义为可复用、参数化的 Composition，适合把文字、
  颜色、时间和布局作为输入。
- 官方 TikTok Caption、Audiogram、Prompt-to-Video 示例分别验证了字幕、
  音频可视化和文字/音频时间线三类模式。
- 社区模板中高频出现大字动效、字幕聚焦、打字/缩放和声波视觉。

本期不直接复制外部模板代码，只提炼交互和视觉模式，保持现有渲染契约、
字体与部署依赖不变。

## 模板集合

1. `tech-text-v1`：深色科技网格，保留现有模板。
2. `kinetic-punch-v1`：高对比色块、超大序号和冲击式大字。
3. `caption-focus-v1`：短视频字幕卡与关键词聚焦。
4. `editorial-card-v1`：纸张留白、衬线排版和观点卡片。
5. `voice-pulse-v1`：口播光环、动态波形和沉浸字幕。

新增模板只要求现有音频与分镜文字；不引入图片或远程字体必填项。

## 数据与交互

- 前后端分别维护同构模板清单，渲染启动前校验精确的 `id@version`。
- 编辑器模板下拉列出全部内置模板；切换后使用目标模板默认参数并立即保存。
- “模板视觉设置”仍编辑当前模板的品牌、色调、强调色和进度条。
- 切换模板不改变音频、时间点或文字，只会使已有成片变为过期状态。
- Remotion Root 为每个模板注册独立 Composition，预览和 worker 导出按同一
  `compositionId` 解析。

## 验证

- 注册表和后端默认值测试覆盖 5 套模板。
- 每套新增模板至少渲染一个 React/Remotion 测试帧。
- 编辑器测试覆盖模板切换参数。
- Next.js 生产构建必须通过。
- 最终用真实项目切换模板并输出一个带 H.264 视频和 AAC 音频的 MP4。
