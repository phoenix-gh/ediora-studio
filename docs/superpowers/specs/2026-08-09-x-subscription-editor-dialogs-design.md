# X 订阅独立编辑窗口设计

## 目标

将 X 页面顶部的“订阅管理”入口改为“新增订阅”，并让每条已有订阅通过左侧列表的编辑入口打开独立的订阅编辑对话框。删除操作也放在该订阅的编辑窗口内。

## 交互

- 顶部“新增订阅”只负责创建时间线或搜索订阅。
- 左侧每条订阅显示编辑按钮；编辑按钮阻止事件冒泡，不改变当前内容流选择。
- 编辑窗口只编辑当前订阅，展示名称、来源、搜索参数（搜索订阅）、启用状态、采集频率、情报分析和素材入库配置。
- 立即采集、回溯采集、AI 筛选入库保留在当前订阅窗口内。
- 删除位于窗口底部危险区，第一次点击进入窗口内确认状态，确认后调用现有删除接口并刷新订阅和帖子。
- 不新增后端接口；时间线 URL 保持只读，因为当前 PATCH 契约不支持修改 URL。

## 实现边界

使用一个支持 `create` / `edit` 两种模式的 `XSubscriptionDialog`，由 X 页面统一提供 CRUD、采集和任务回调。订阅列表不再通过总管理对话框渲染，避免多条订阅状态混在一个编辑上下文中。

## 验证

聚焦验证新增按钮、独立编辑窗口、搜索订阅字段回填、素材入库规则、删除确认及事件冒泡隔离；随后运行 X 页面相关 Vitest、ESLint 和目标页面 Playwright 交互检查。
