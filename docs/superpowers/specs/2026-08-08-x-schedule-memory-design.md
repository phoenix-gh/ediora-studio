# X 安排表最后选择记忆设计

## 目标

把现有的 X 安排表最后选择记忆脚本集成到“述策助手”扩展中，使扩展能够：

- 记住 X 安排表最近一次选择的日期和时间；
- 再次打开安排表时恢复这组选择；
- 记录手工操作和插件自动设置的时间；
- 在悬浮发布指挥台中显示“上次安排：YYYY-MM-DD HH:mm”。

继续使用页面本地存储键 `x_schedule_last_selection_v3`，兼容用户已有的五字段数据。新增的 `period` 字段可选，用于兼容 X 的六个下拉框（包括 AM/PM）。

## 范围边界

本次不增加任何 DevTools 或 `Shuce` 控制台接口，并移除现有的 `Shuce.publish` 页面注入入口和消息桥接。内部发布器和 X DOM 驱动暂时保留，供后续正式 UI 复用；本次不写入后端，不把帖子正文或登录凭据保存到扩展存储，也不改变内部发布器的参数契约。

## 设计

### 1. 安排表记忆模块

新增独立的 `content/schedule-memory.js`，负责两类职责：

- 存储层：安全读取、校验、写入和格式化 `x_schedule_last_selection_v3`；`localStorage` 不可用时降级为空状态，不阻断发布流程。
- 页面监听层：以当前安排表对话框为边界，每约 300ms 检查对话框是否打开，首次打开后恢复已保存值。保存通过捕获阶段监听 X 的确定按钮 `data-testid="scheduledConfirmationPrimaryAction"` 的 click 触发，在 X 关闭对话框前读取并写回当前控件。
- 下拉框或输入框变化期间不写入存储，避免中间选择覆盖历史值；点击取消或关闭对话框也不保存。

监听器复用现有安排表控件识别规则，支持：

- X 当前的 month/day/year/hour/minute/AM-PM 下拉框；
- X 提供的日期输入框和时间输入框；
- 用户脚本留下的五字段旧值。

恢复期间禁止保存中间状态，避免 X 每次重建控件时把半成品覆盖到历史值。找不到旧值或某个旧选项已不存在时，不清空历史值，并让当前页面继续使用。

### 2. 确定按钮保存流程

页面级 click 捕获在 X 确定按钮的处理逻辑之前执行，调用 `saveCurrent()` 读取并保存最终选择。这样 X 立即关闭安排表对话框时也不会丢失最后时间。

`x-dom-driver.setScheduleFields()` 只负责设置并回读控件，不直接写入记忆；手工操作和内部驱动都由同一个确定按钮 click 保存。现有发布校验、回读验证和提交逻辑不变。

### 3. 指挥台展示

悬浮指挥台头部新增一个状态胶囊：

- 有记录：显示 `上次安排：2026-08-08 20:30`；
- 没有记录：显示 `上次安排：未记录`。

状态来自页面本地存储，并由监听器在同一页面内更新。指挥台关闭时仍不执行发布操作；该区域只有信息展示，不提供额外的编辑、清除或 DevTools/控制台入口。

### 4. 移除旧 DevTools 接口

Manifest 不再加载 `content/bridge.js`，也不再声明 `injected/console-api.js`、`content/bridge-protocol.js` 和仅由桥接使用的发布器资源。页面上不再创建 `window.Shuce`，不再监听或发送 `SHUCE_PUBLISH_REQUEST` / `SHUCE_PUBLISH_RESULT` 消息。

桥接、注入 API 及其专属测试一并删除；内部 `publisher.js`、`x-dom-driver.js`、`selectors.js` 和相关合同测试先保留，避免把后续正式发布 UI 的基础能力与本次接口移除混在一起。

## 数据格式

写入格式保持与现有脚本兼容：

```json
{
  "month": "8",
  "day": "8",
  "year": "2026",
  "hour": "8",
  "minute": "30",
  "period": "PM"
}
```

`period` 缺失时按旧脚本的原始小时值展示和恢复，不猜测上午或下午。输入框模式可将 `hour` 写成 24 小时值，并省略 `period`。

## 错误与兼容

- 历史值 JSON 损坏、字段缺失或值不合法时视为“未记录”，不影响草稿指挥台和发布功能。
- X 页面控件发生变化时，记忆模块不抛出未处理异常；插件原有的 `SCHEDULE_CONTROLS_CHANGED` 错误处理继续负责定时发布失败。
- 旧版脚本和扩展同时存在时使用同一个 key，任一方写入的有效值都可被另一方读取。

## 验证

新增测试覆盖：

- 五字段旧数据的读取、格式化与恢复兼容；
- 六字段数据的 period 保存和展示；
- 无效 JSON/存储异常的安全降级；
- 只有确定按钮 click 才保存当前时间，轮询和取消操作不写入；
- 指挥台存在上次安排状态的 UI 标记。
- Manifest 不再注入 `Shuce`，且旧桥接文件和测试不再存在。

运行扩展全量 Node 测试、所有扩展 JavaScript 语法检查和 `git diff --check`。
