# 自动正文配图插入

## 目标

自动正文配图任务生成图片后，将图片插入到对应文章段落，而不是仅保存到草稿资产库。

## 范围

- 仅处理 `illustrations` 正文配图任务。
- 封面图片继续仅保存在资产库，不插入文章正文。
- 不改变手动上传、手动插图或发布流程。

## 数据流

1. 插图生成器为每张图片选择一个文章二级标题作为锚点。
2. 图片上传并取得资产 URL 后，任务把 Markdown 图片语法插入该锚点标题之后。
3. 若锚点不存在，图片追加到正文末尾。
4. 已含相同图片 URL 时跳过插入，确保任务重试不会重复图片。

## 已有资产补偿

为已有的、仅存在资产库而未写入正文的插图提供一次“补插入正文”操作；该操作复用同一锚点与去重规则。

## 错误与审计

- 上传成功但正文写回失败时，任务失败并保留已上传资产，供重试或补插入操作使用。
- 任务事件记录图片 URL、锚点和最终插入位置，便于定位问题。

## 验证

- 有匹配二级标题时，图片紧随标题插入。
- 无匹配标题时，图片追加在文末。
- 对同一资产重复执行不会产生重复 Markdown 图片。
- 封面任务不修改正文。
