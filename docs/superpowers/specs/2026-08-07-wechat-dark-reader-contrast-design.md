# 公众号深色主题阅读区可读性修复

## 背景

公众号正文 HTML 包含大量面向浅色页面编写的内联颜色，例如
`color: rgba(0,0,0,.9)` 和 `color: #3f3f3f`。当前阅读器在深色主题下使用
深色背景；Tailwind Typography 的 `prose-invert` 无法覆盖这些内联颜色，导致
正文与背景对比不足。

## 设计

公众号仍复用通用 `ArticleReader`，但为阅读器增加可选的浅色正文画布模式。
开启该模式时：

- 标题栏、面板边框和页面其余区域继续跟随系统深色主题；
- 仅富文本正文区域使用浅色纸张背景和深色基础文字；
- 保留公众号 HTML 原有的内联强调色、图片、表格和排版；
- 不修改数据库内容，也不在客户端清洗或重写正文 HTML；
- 其他内容源继续使用现有的主题自适应正文样式。

公众号页面在调用 `ResponsiveArticleReader` 时开启该模式。通用阅读器通过明确的
属性控制行为，避免根据 `platform` 或正文内容做隐式判断。

## 测试与验收

1. 组件测试先证明公众号阅读器会请求浅色正文画布，并验证默认阅读器行为不变。
2. 在 `/wechat` 切换深色主题，打开一篇包含内联深色文字的文章。
3. 验证正文画布为浅色、文字可读，外层界面仍为深色。
4. 检查页面无框架错误覆盖层，并检查相关控制台错误。

## 非目标

- 不重新设计公众号页面布局；
- 不修改公众号正文抓取和存储逻辑；
- 不尝试将任意内联颜色自动转换为深色主题色；
- 不改变其他内容源的阅读器视觉效果。
