# 文字视频模板品牌与视觉设置设计

## 目标

移除第一款 Remotion 模板左上角硬编码的 `WEMEDIA / TEXT SIGNAL`，使平台品牌改名能够反映到新建文字视频中。同时建立可扩展的模板设置机制：平台提供默认值，每个作品保存自己的覆盖值，不同模板可以声明不同的可配置项。

## 当前问题

`tech-text-v1` 的品牌文字、强调色、背景和辅助元素直接写在 Remotion 组件中。现有 `templateProps` 只支持固定的主题、字体、背景、转场和文字密度，编辑器也没有模板级设置入口。因此：

- 产品名称已经改为 `Ediora · 述策`，模板仍显示旧品牌；
- 用户无法隐藏或修改品牌条；
- 用户无法调整强调色、背景、进度条和场景编号；
- 后续模板即使拥有不同参数，也没有统一的设置描述与编辑机制。

## 方案选择

采用“平台默认值 + 作品覆盖”：

- 平台设置保存每个模板的默认参数；
- 创建作品时复制当时的默认参数；
- 每个作品独立保存完整的模板参数快照；
- 修改平台默认值只影响后续新作品，不隐式修改已有作品。

不采用只读平台品牌的方案，因为不同频道和作品可能需要不同视觉身份；也不采用仅作品级设置的方案，因为每次新建作品都重复配置会增加操作成本。

## 参数契约

### 第一模板参数

`tech-text-v1` 保留现有字段并增加以下字段：

| 字段 | 类型 | 默认值 | 约束 | 用途 |
| --- | --- | --- | --- | --- |
| `brandTitle` | string | `EDIORA` | 去除首尾空格，最多 32 个字符 | 品牌主标题 |
| `brandSubtitle` | string | `述策` | 去除首尾空格，最多 32 个字符，可为空 | 品牌副标题 |
| `showBrand` | boolean | `true` | — | 显示或隐藏整个品牌条 |
| `accentColor` | string | `#69F6FF` | 六位十六进制颜色 | 高亮线、进度条和光晕颜色 |
| `background` | enum | `dark-grid` | `dark-grid`、`deep-space`、`clean-gradient` | 模板背景样式 |
| `showProgress` | boolean | `true` | — | 显示或隐藏底部进度条 |
| `showSceneNumber` | boolean | `true` | — | 显示或隐藏当前场景编号 |

现有 `textDensity` 继续提供 `compact`、`standard`、`spacious` 三档。第一期不开放自由字体、自由坐标、字号和任意 CSS，避免产生无法保证安全区与多画幅适配的组合。

品牌条显示规则：

- `showBrand=false` 时，品牌线、主标题和副标题全部隐藏；
- 副标题为空时只显示主标题，不出现多余分隔符；
- 主标题和副标题都为空时按隐藏品牌条处理；
- 默认组合显示为 `EDIORA / 述策`。

### 模板设置描述

模板清单增加只包含可序列化数据的设置描述，声明字段的键、标签、控件类型、分组、约束和选项。编辑器根据描述生成表单，不为 `tech-text-v1` 写专用表单。

设置描述支持第一期所需的四类控件：

- 单行文本；
- 布尔开关；
- 枚举选择；
- 颜色选择与十六进制输入。

Remotion 的 Zod schema 和后端镜像清单仍是最终校验边界。设置描述只负责界面呈现，不能绕过契约校验。

## 平台默认设置

设置页新增“文字视频”分类，展示当前可用模板。选择模板后编辑其默认值。

后端配置保存一个按模板身份分组的 JSON 对象：

```json
{
  "tech-text-v1@1": {
    "brandTitle": "EDIORA",
    "brandSubtitle": "述策",
    "showBrand": true,
    "accentColor": "#69F6FF",
    "background": "dark-grid",
    "showProgress": true,
    "showSceneNumber": true,
    "textDensity": "standard"
  }
}
```

保存前必须通过对应模板的后端参数清单校验。配置不存在或部分字段缺失时，使用代码内模板默认值补齐。未知模板、未知字段和非法值返回明确的 `422` 错误，不保存部分结果。

## 作品编辑交互

文字视频编辑页的模板区域增加“模板设置”按钮，点击后打开对话框，不使用侧边抽屉。

对话框按以下分组展示：

1. 品牌：主标题、副标题、品牌显示开关；
2. 视觉：强调色、背景样式、文字密度；
3. 辅助元素：进度条和场景编号开关。

交互规则：

- 打开时以当前作品的 `render_input.templateProps` 初始化；
- 表单修改立即反映到对话框内的模板预览，但不立即写入项目；
- “取消”丢弃本次修改；
- “应用并保存”通过项目更新接口保存完整参数；
- “恢复平台默认值”先把表单替换成当前平台默认值，仍需点击“应用并保存”才写入作品；
- 字段错误显示在对应控件旁，后端失败时保留用户输入并显示错误；
- 保存成功后关闭对话框并刷新主预览。

## 数据流与状态失效

### 新建作品

1. 后端解析所选模板；
2. 读取该模板的平台默认配置；
3. 用模板代码默认值补齐缺失字段；
4. 校验后把完整快照写入新作品的 `render_input.templateProps`。

### 修改已有作品

1. 编辑器提交完整的 `templateProps`；
2. 后端根据作品的 `templateId` 和 `templateVersion` 校验；
3. 参数未发生变化时不增加项目修订号，也不失效任何产物；
4. 参数发生变化时保存新快照；如果项目已有视频输出，将其 `output_stale` 标记为 `true`；
5. 音频、逐字对齐、分镜文本和时间轴保持有效。

保存与当前项目修订机制协作；遇到修订冲突时沿用现有冲突处理，不静默覆盖另一页面的更新。

### 成片状态

文字视频项目增加持久化的 `output_stale` 布尔字段，默认值为 `false`：

- 没有 `output_asset_url` 时不显示过期提示；
- 有成片且模板、画幅或分镜视觉参数发生变化时设为 `true`；
- 旧成片地址继续保留，并标注为“上一版成片”；
- 新成片成功保存后设为 `false`；
- 音频和时间轴状态不受该字段影响。

## 旧项目与旧成片

新增字段作为模板缺省参数处理，旧项目读取时能够补齐，不因严格 schema 缺字段而无法打开。

增加幂等数据迁移，处理 `tech-text-v1@1` 中缺少本次新增参数的项目：

- 用模板代码默认值补齐并持久化完整 `templateProps`；
- 如果项目已有 `output_asset_url`，将 `output_stale` 设为 `true`；
- 不采用用户后来修改的平台默认值改写旧作品；
- 不删除或覆盖任何历史 MP4。

迁移后的旧项目打开时：

- 编辑预览使用已补齐的 `EDIORA / 述策` 品牌；
- 如果已有 MP4 是按旧硬编码模板生成，页面保留上一版成片并提示需要重新渲染；
- 用户重新生成视频后得到新品牌版本；
- 不重新生成语音、字幕、分镜或全局时间轴。

本次修复属于第一模板的品牌缺陷修正，保持 `tech-text-v1@1` 身份不变；新增字段全部有兼容默认值。若未来出现会改变既有参数含义或无法向后兼容的变化，再提升模板版本。

## 渲染规则

Remotion 组件只能从已校验的 `templateProps` 读取可配置元素，不再读取页面标题或散落的品牌常量。

- `accentColor` 同时控制品牌短线、进度条和对应光晕；
- 背景样式由模板内部预定义映射生成，用户不能注入 CSS；
- 所有画幅继续使用模板的相对安全区；
- 隐藏某个元素后，其位置不保留不可见占位；
- 编辑器预览和 Worker 最终渲染使用同一模板组件与同一参数快照。

## 错误处理

- 客户端在提交前检查必需字段、长度、枚举值和颜色格式；
- 后端始终重新校验，不信任客户端设置描述；
- 平台默认配置损坏时记录错误并回退到代码默认值，新作品创建不能因此中断；
- 作品参数非法时拒绝保存，保留最后一个有效项目版本；
- Worker 收到无法解析的参数时任务失败并报告具体模板字段，不生成不完整视频。

## 测试与验收

### 契约测试

1. 前端和后端清单接受所有合法新字段；
2. 缺少新字段的旧参数可以补齐默认值；
3. 未知字段、非法颜色、超长文字和非法枚举被拒绝；
4. 模板设置描述中的默认值与渲染 schema 默认值一致。

### 设置测试

1. 设置页可以读取、修改并持久化第一模板默认值；
2. 新作品继承保存时的平台默认值；
3. 修改平台默认值不会改变已有作品；
4. 损坏或缺失的平台配置安全回退到 `EDIORA / 述策`。

### 编辑器测试

1. 模板设置使用对话框打开；
2. 取消不修改项目，保存更新当前作品；
3. 恢复默认只修改对话框草稿，确认后才保存；
4. 校验错误定位到对应字段；
5. 模板参数改变时只把已有成片标记为过期，旧地址仍然可用，音频和时间轴保持就绪；
6. 未改变参数时不产生无意义修订。

### 渲染测试

1. 第一模板默认显示 `EDIORA / 述策`，代码中不再存在可见的 `WEMEDIA`；
2. 品牌显示、进度条和场景编号开关均影响预览与最终渲染；
3. 三种背景、强调色和三档文字密度在 `9:16`、`16:9`、`1:1` 下正确显示；
4. 旧项目可以打开并重新渲染，不需要重新生成音频或分镜；
5. 相同参数的浏览器预览与 Worker 输出保持一致。

### 迁移测试

1. 缺少新增参数的第一模板项目被补齐，重复执行迁移不再改变数据；
2. 有旧成片的项目保留原地址并设置 `output_stale=true`；
3. 没有成片的项目不显示过期状态；
4. 其他模板和已经拥有完整新参数的项目不被修改。

## 范围外

- 上传品牌 Logo 图片；
- 为元素提供自由拖拽定位；
- 自定义字体文件；
- 让 AI 自动生成模板主题；
- 批量重写所有历史 MP4；
- 跨模板复制无法对应的专有参数。
