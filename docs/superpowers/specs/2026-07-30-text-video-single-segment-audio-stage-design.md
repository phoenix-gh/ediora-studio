# 文字视频单段配音界面设计

## 目标

当稿件只有一个非空口播段落时，第二步“配音制作”不再展示独立的“主音频与全局时间轴”卡片。用户只需要理解为：试听并确认当前配音，系统随后自动准备成片时间轴。

## 问题

单段模式下，确认后的段落音频会被底层直接复用为标准主音频，不会再次合成或编码。当前界面仍展示另一张主音频卡片、重复播放器和“播放全部”操作，会让用户误以为需要再生成一份音频。

## 设计决策

### 单段模式

- “当前段配音”是唯一可见的音频卡片。
- 不展示“主音频与全局时间轴”标题、主音频播放器、“播放全部”或“生成主音频”操作。
- 段落确认后，系统继续自动复用该音频并建立标准时间轴。
- 时间轴状态作为“当前段配音”卡片底部的紧凑状态区展示：
  - 尚未确认：不展示时间轴状态；
  - 正在准备：`正在生成成片时间轴`；
  - 已完成：`成片时间轴已就绪`；
  - 已失败：展示实际错误和对应恢复操作。
- 标准音频准备失败时，恢复操作为`重新准备时间轴`，内部仍调用现有主音频构建动作。
- 已有标准音频但逐字对齐失败时，恢复操作为`重新对齐`，内部仍调用现有对齐动作。
- 页面底部阶段提示继续使用“成片时间轴”，不向用户暴露“主音频”概念。

### 多段模式

- 保留独立的音频汇总卡片。
- 卡片名称调整为“合成音频与成片时间轴”，准确表达多个已确认片段需要合成。
- 保留合成音频播放器、“播放全部”、生成或重新生成合成音频以及重新对齐操作。

## 技术边界

- 不改变后端、数据库或 API 中的 `master_audio` 数据结构和状态机。
- 不改变单段确认后自动调用主音频构建任务的行为。
- 不改变进入视频合成前 `master_audio.status` 和 `timeline_status` 必须就绪的校验。
- 不改变多段音频的合成、播放和失败恢复流程。
- 本次只调整第二步的可见信息架构、文案与相关前端测试。

## 验收标准

1. 单段项目中只出现一个音频播放器，且不存在“主音频”“播放全部”和独立主音频卡片。
2. 单段时间轴正在生成、成功和失败状态都显示在“当前段配音”卡片中。
3. 单段标准音频准备失败可以在当前段卡片中重新准备。
4. 单段逐字对齐失败可以在当前段卡片中重新对齐。
5. 多段项目仍可生成、播放和重新生成合成音频。
6. 多段独立卡片使用“合成音频与成片时间轴”名称。
7. 现有单段自动复用、项目保存和进入视频合成的行为保持不变。
