# 创作资产多媒体批量上传设计

## 目标

在“创作资产 → 多媒体”中增加明确的上传入口。用户点击“上传”后进入批量上传 Dialog，可以选择、拖拽或直接粘贴多个图片、视频和音频文件，并能逐项查看和处理上传结果。

本次只补齐已有多媒体上传 API 的前端交互，不改变多媒体资产模型、目录模型或预览方式。

## 入口与目录归属

- 多媒体工具栏显示“上传”按钮；文章和提示词工作区不显示该入口。
- 点击按钮打开批量上传 Dialog。
- 打开 Dialog 时记录当前选中的多媒体目录。本次队列中所有文件上传到该目录；空目录表示多媒体根目录。
- Dialog 打开期间切换或刷新外部目录，不改变当前队列的目标目录，避免同一批文件被拆到不同目录。
- Dialog 中展示目标目录名称，让归属可见。

## 添加文件

Dialog 顶部提供统一的文件接收区，支持三种方式：

1. 点击后打开系统文件选择器；
2. 将多个文件拖入接收区；
3. Dialog 打开时，通过 `Ctrl/Cmd + V` 粘贴剪贴板中的一个或多个文件或图片。

接收图片、视频和音频，按文件 MIME 类型自动识别 `image`、`video` 或 `audio`，不要求用户预先选择类型。普通文字、网页 URL 或不支持的文件类型不进入队列，并显示清晰提示；系统不根据 URL 自动下载外部资源。

同一次待上传队列中，文件名、大小、类型和最后修改时间均相同的文件视为重复项，只保留一项并提示已忽略重复文件。

## 上传队列

每个队列项显示：

- 文件名；
- 文件类型和大小；
- 图片缩略图，或视频/音频类型图标；
- 当前状态：待上传、上传中、成功或失败；
- 失败原因和单项重试操作。

上传开始前，用户可以删除单项或清空队列。主按钮显示“上传 N 个文件”；没有待上传项时禁用。

## 执行与反馈

- 用户确认后开始上传，同时最多执行 3 个请求。
- 每个文件独立调用现有多媒体上传 API；单项失败不阻塞其他文件。
- 成功项立即加入当前页面的资产列表，并从待处理队列中移除。
- 失败项保留在 Dialog 中，可以单独重试或再次批量重试。
- 全部成功后自动关闭 Dialog，并显示成功数量。
- 部分失败时保持 Dialog 打开，汇总成功与失败数量。
- 上传过程中禁用目标目录变化、重复提交和删除正在上传的项目，但允许关闭 Dialog 前先确认。

## 关闭行为

- 队列为空或全部完成时可以直接关闭。
- 存在待上传、上传中或失败项目时，关闭 Dialog 需要确认。
- 关闭 Dialog 不删除已经成功上传的资产。
- 对仍在进行的浏览器请求不做破坏性强制取消；关闭后忽略其界面回写，随后刷新资产列表以服务器结果为准。

## 错误边界

- 前端在入队时拒绝不能识别为图片、视频或音频的文件。
- 后端仍作为文件类型和安全校验的最终边界。
- 网络错误、服务端拒绝和未知错误均落到具体队列项，不用一条全局错误覆盖批量结果。
- 粘贴事件只在 Dialog 打开且焦点位于 Dialog 内时处理，避免影响页面其他输入框。

## 验证

前端组件测试至少覆盖：

- 多媒体工具栏存在上传入口，其他资产类型没有；
- 多文件选择、拖拽和剪贴板粘贴均能建立队列；
- 普通文字、URL、不支持类型和重复文件的处理；
- 当前目录传给每次上传；
- 并发上限为 3；
- 成功资产即时加入列表，失败项保留并可重试；
- 未完成队列的关闭确认；
- Dialog 外的粘贴不触发上传。

后端已有上传接口若保持契约不变，只运行其现有聚焦回归；不为本次前端功能新增后端批量端点。
