# YouTube 中英对照逐字稿设计

## 目标

在已有“原文 / 中文”逐字稿版本切换基础上增加“中英”模式。中英模式以原文句子为主轴，每组先显示原文，下一行显示对应中文字幕，并继续支持时间戳跳转、独立滚动和复制全文。

## 范围与数据边界

- 继续使用现有逐字稿 API 返回的原文 `segments` 和可选 `chinese.segments`。
- 对齐只在前端查看时计算，不修改数据库、API 或采集结果。
- 只有同时存在原文与独立中文版本时显示“原文 / 中文 / 中英”切换。
- 原语言本身为中文或没有独立中文字幕时，不显示“中英”。

## 时间轴对齐

原文分段是展示主轴。中文字幕按时间顺序处理，每条中文只分配一次：

1. 计算该中文分段与所有原文分段的时间重叠长度。
2. 存在正重叠时，分配给重叠长度最大的原文；相同时选择时间更早的原文。
3. 没有重叠时，若中文分段与最近原文分段的区间距离不超过 1.5 秒，则分配给该原文；距离相同时选择更早的原文。
4. 一句原文可以接收多条中文；按中文字幕时间顺序保留为多行，不拼接或改写字幕文字。
5. 仍无法匹配的中文作为中文独立组按时间顺序插入，避免内容丢失。

缺失、非有限或结束早于开始的时间范围不参与距离匹配。这类内容作为未匹配中文保留；非法原文分段仍按原顺序显示，但时间戳不可点击。

## 展示

- 版本切换顺序为“原文 / 中文 / 中英”，打开弹窗仍默认“原文”。
- 中英组左侧只显示主时间戳。正常配对组使用原文开始时间；中文独立组使用中文开始时间。
- 右侧第一层显示原文，中文以略小、次要颜色显示在其下方。
- 一句原文对应多条中文时逐行显示这些中文，不压成一行。
- 中文独立组不伪造原文，使用“仅中文”语义化标记。
- 内容区继续使用现有有界高度和 `overflow-y-auto`。

## 复制

“复制全文”跟随当前模式：

- 原文模式复制现有原文 `text`。
- 中文模式复制现有中文 `text`。
- 中英模式按当前对齐顺序生成文本：原文一行，匹配中文各一行，句组之间空一行。
- 中文独立组只复制中文行，不增加虚构原文。
- 空白文本不写入剪贴板；全部为空时禁用复制。

## 实现边界

- 在 `YoutubeTranscriptDialog.tsx` 导出纯函数完成对齐和中英复制文本生成，保持组件渲染逻辑可测试。
- 不引入新依赖，不调用 AI，不做语义翻译或文本相似度匹配。
- 保留现有原文、中文、加载失败、空内容和复制反馈行为。

## 验证

- 单元测试覆盖一对一、一对多、最大重叠、无重叠但距离在 1.5 秒内、距离过远的中文独立组、非法时间范围和中文不重复分配。
- 组件测试覆盖第三个切换按钮、默认原文、中英渲染顺序、中文独立组、复制中英格式和无中文时隐藏中英模式。
- 运行该组件聚焦测试、YouTube 前端相关测试、相关 ESLint 和 `git diff --check`。
