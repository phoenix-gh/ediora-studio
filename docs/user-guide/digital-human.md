# 制作数字人口播

数字人口播把脚本、人物形象、声音样本和环境图组合成 16:9 的 MP4 口播视频。当前支持 HeyGen 和 ComfyUI / MiniMax H3 两种制作方式。

## 完成后你将得到什么

完成整个流程后，你会得到：

- 一个可在多个作品中复用的数字人角色；
- 一份自动保存的口播脚本和作品配置；
- 可播放并可切换历史版本的口播成片。

## 开始前的准备

先选择适合自己的生成方式：

| 生成方式 | 适合的情况 | 开始前需要配置 |
| --- | --- | --- |
| HeyGen | 希望按完整脚本直接生成一版口播视频 | “设置 → HeyGen”中的 API Key，并完成连接测试 |
| ComfyUI / MiniMax H3 | 希望逐镜规划、调整和生成，再拼接成片 | “设置 → ComfyUI”中的运行环境与连接；使用仙宫云时还需完成“设置 → 仙宫云” |

两种方式都需要：

- 一张正面、光线均匀、无遮挡的 PNG 或 JPEG 人像；
- 一段清晰的单人声音样本，格式为 MP3 或 WAV；
- 一张 PNG 或 JPEG 环境图，或可用于生成环境图的文字描述。

上传的单个素材不能超过 32MB。ComfyUI 角色的声音样本应为 2–15 秒。完整的基础设置说明见[首次使用设置](setup.md)。

## 创建数字人角色

1. 从左侧导航进入“数字人口播”。
2. 点击“创建数字人”。
3. 选择“HeyGen”或“ComfyUI / MiniMax H3”。渲染后端在角色创建后不能更改。
4. 填写角色名称。
5. 从创作资产选择或上传人物形象和声音样本。
6. 选择默认环境。你可以上传图片、选择已有创作资产，也可以输入环境描述后点击“生成并使用”。
7. 使用 ComfyUI 时，可填写“定妆说明”，描述姿态、构图和动作。
8. 点击“保存并开始处理”。

等待角色状态变成“已就绪”后，才能用它创建口播作品。ComfyUI 会先生成定妆图；HeyGen 会处理人物形象和声音。

## 创建口播作品

角色就绪后，可以从角色卡片点击“新建口播”，也可以：

1. 切换到“口播作品”。
2. 点击“新建口播作品”。
3. 填写作品名称并选择一个已就绪角色。
4. 点击“创建并编辑”。

新作品默认使用角色的环境图，进入编辑器后仍可替换。角色或环境变化时，先等自动保存完成，再开始生成。

## 编写或转换口播脚本

在“口播脚本”中输入最终要朗读的内容。也可以点击“AI 辅助”，选择：

- “根据主题生成”：输入主题和要求，得到一版候选脚本；
- “从草稿转换”：把已有草稿改写成口播表达；
- “改写当前脚本”：在现有内容基础上调整语气或结构。

AI 生成的内容只是候选结果。检查无误后点击“使用这个脚本”，它才会替换当前作品中的脚本。脚本属于当前口播作品，不会另外进入脚本库。

## 选择环境并生成版本

### 使用 HeyGen

1. 确认角色、环境和口播脚本。
2. 点击“生成新版本”。
3. 在确认窗口中点击“确认生成”。
4. 等待状态从“等待中”或“生成中”变为“已完成”。

提交后，当前脚本、角色与环境会冻结为一个新版本，已有版本不会被覆盖。

### 使用 ComfyUI / MiniMax H3

1. 完成脚本的镜头规划，检查每镜的口播内容、构图、动作和提示词。
2. 选中一个镜头，点击“生成这一镜”进行试做；已有结果的镜头会要求确认后再重新生成。
3. 确认设置后，点击“全部入队生成”处理所有未完成镜头。
4. 逐镜查看结果。全部镜头完成后，点击“生成成片”。

如果按钮提示“还缺 2–15 秒声音样本”，请回到“数字人角色”编辑该角色并补充合格录音。

## 查看和管理生成结果

右侧“成片预览”用于播放当前结果。“历史版本”会保留每次生成的独立记录：

- 已完成的旧版本可以“设为当前”；
- 等待中或生成中的版本可以停止；
- 失败或已取消的版本可以删除；
- 失败时先查看版本显示的原因，再到[任务概览](task-management.md)确认任务详情。

ComfyUI 作品还可以在“本镜”和“成片”之间切换预览。重新生成某一镜会替换工作台中该镜的预览结果；确认满意后再重新拼接成片。

## 当前能力边界

- 角色的 HeyGen 或 ComfyUI 后端一经创建不能切换；需要另一种方式时，请新建角色。
- 只有状态为“已就绪”的角色可以创建口播作品。
- 当前成片为 16:9 MP4，不自动添加字幕和背景音乐。
- HeyGen 生成会调用第三方服务；ComfyUI 生成依赖已配置且可访问的运行环境。耗时和费用取决于实际配置。
- AI 脚本不会自动采用，必须点击“使用这个脚本”。

## 常见问题

**“新建口播作品”按钮不可用怎么办？**

先到“数字人角色”确认至少有一个角色处于“已就绪”。若角色仍在处理，等待页面刷新状态；若处理失败，编辑角色检查素材和对应服务配置。

**生成按钮不可用怎么办？**

检查脚本是否为空、角色是否已就绪、声音样本是否符合要求，以及当前是否已有生成任务进行中。ComfyUI 还需要先完成镜头规划。

**换了脚本或环境，旧版本为什么没有变化？**

每个已提交版本都会保留当时的脚本、角色和环境。修改只影响下一次生成，不会覆盖历史版本。

**环境图生成失败怎么办？**

前往“任务概览”查看对应任务的失败说明，再检查 AI 图像配置。详细方法见[常见问题与排查](troubleshooting.md)。
