# 编辑草稿并完成发布前准备

生成的草稿是可编辑起点，不应直接视为最终成稿。发布前需要核对标题、事实、来源、图片和目标平台格式，并明确保存最新修改。

## 完成后你将得到什么

完成本章后，你将拥有一篇内容已核对、修改已保存、素材状态明确，并适合进入目标平台发布流程的草稿。

## 打开并编辑草稿

1. 从主导航打开 **创作 → 草稿箱**。
   左侧显示草稿列表，右侧是当前草稿的编辑区域。

2. 如果没有看到目标草稿，把“按主题筛选”和“按状态筛选”改为“全部主题”和“全部状态”。
   列表会重新加载符合条件的草稿。

3. 点击目标草稿。
   右侧会显示当前状态、关联写作模板、版本、字数、标题和正文。

4. 把状态改为“编辑中”，然后修改标题和正文。
   内容发生变化后，工具栏会显示“有未保存修改”，同时“保存”按钮变为可用。

## 保存修改

1. 完成一轮修改后点击“保存”。
   保存成功时会看到“已保存”，并且“有未保存修改”提示消失。

2. 在切换到另一篇草稿前再次确认没有未保存提示。
   如果仍有修改，页面会在离开前提醒；选择继续编辑并先保存，可以避免覆盖或丢失内容。

3. 发布前把状态改为“待发布”，再点击“保存”。
   左侧草稿条目会显示“待发布”，便于与仍在写作的内容区分。

> **提示：** AI 写作建议应用到正文后仍属于未保存修改。看到“已应用到草稿，记得保存”时，必须再点击一次“保存”。

## 检查标题和正文

逐项检查：

- 标题是否准确表达文章内容，没有把预发布版本写成正式发布；
- 版本号、产品名、模型名、日期和数字是否与原始来源一致；
- 重要结论是否能从“灵感”中的来源链接核实；
- 正文是否符合所选发布账号的受众、调性和禁区；
- 链接是否可以打开，引用是否保留必要上下文；
- 开头、段落和结尾是否适合目标平台阅读。

点击“灵感”可以查看或补充来源 URL、标题和备注。删除来源不会自动改写正文，因此修改来源后还要重新核对相关内容。

## 管理封面和正文图片

1. 点击工具栏中的“素材”，打开“图片素材”。
   页面会显示当前草稿已有图片和大图预览。

2. 需要自备图片时点击“上传”。
   上传成功后，图片会出现在缩略图列表；选择图片并点击“插入”，可以把它加入当前正文。

3. 需要 AI 封面时，选择“AI 生成封面”或“重生成封面”，再选择发布账号并提交。
   任务创建成功后需要等待生成结果。名称以 `cover` 开头的图片会被识别为封面。

4. 需要正文插图时，点击“自动配图”，选择发布账号和最多插图数量，然后点击“开始配图”。
   系统会创建配图任务；完成后重新打开素材或刷新图片列表确认结果。

> **注意：** 重新执行自动配图会替换上一轮自动插图，图片生成也可能产生模型费用。先保存正文，并确认确实需要重跑。

上传或生成的图片还应检查：

- 是否拥有使用权；
- 是否包含不应公开的个人信息；
- 图中文字、品牌和事实是否准确；
- 尺寸和构图是否适合目标平台；
- 封面是否已经明确选定。

## 检查发布账号与目标平台

1. 点击工具栏中的“发布”。
   页面会打开发布窗口，并提供“公众号”“X 长文”和“Blog”标签。

2. 选择目标平台，先查看预览和平台提示。
   不同平台的要求不同：

   - 公众号需要可用的公众号账号、标题、摘要和封面，最终操作是“存入公众号草稿箱”；
   - X 长文提供预览和复制，仍需到 x.com 文章编辑器手动设置标题、封面和图片；
   - Blog 提交后进入审核状态，需要人工确认后发布。

3. 关闭发布窗口，修正预览中发现的问题，然后再次保存草稿。
   仅打开预览不会自动修改正文。

> **提示：** 本使用主线到“草稿已做好发布准备”为止。你可以在账号权限、封面和平台设置全部确认后，再执行真实发布。

## 完成发布前检查

- [ ] 标题准确，没有夸大版本状态或功能范围；
- [ ] 正文中的关键事实、数字和链接已经核对；
- [ ] 草稿状态已设为“待发布”；
- [ ] 页面不再显示“有未保存修改”；
- [ ] 来源链接完整且可以访问；
- [ ] 图片拥有使用权，没有敏感信息；
- [ ] 封面和正文图片已经确认；
- [ ] 发布账号与文章受众一致；
- [ ] 目标平台预览没有明显格式问题；
- [ ] 已了解该平台是直接存入草稿箱、复制后手动发布，还是提交审核。

## 常见问题

### “保存”按钮不可用

当前内容没有未保存变化时，按钮会保持不可用。修改标题、正文、状态或关联写作模板后，按钮会启用。

### 生成了图片，但正文中看不到

打开“素材”，选择目标图片并点击“插入”。图片存在于素材列表不等于已经插入正文。

### 公众号发布按钮不可用

检查是否选择了可用的公众号账号，标题是否为空，以及素材中是否存在封面图。公众号账号还需要在 **设置 → 发布账号** 中配置相应发布凭据。

### X 长文粘贴后图片或格式丢失

X 长文采用手动发布流程。标题和封面需要在 X 编辑器中单独设置，正文图片通常也要手动上传；发布窗口会提示不兼容的 Markdown 格式。

## 下一步

核心流程已经完成。需要继续制作多媒体内容时，可以从这篇草稿出发使用文字视频或数字人口播；遇到异常时参阅[常见问题排查](troubleshooting.md)。
