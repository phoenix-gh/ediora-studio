# 问题排查

本章按照“你看到了什么”来排查跨功能问题。先找到最接近的现象，完成对应检查，再执行一次安全的下一步；不要通过连续刷新、重复创建或反复重试来碰运气。

## AI 模型未配置或不可用

**你可能看到：**

- “请先在设置中配置文本模型 API Key”；
- “请先在设置中配置图片模型 API Key”；
- 模型连接测试失败；
- 创作任务提示模型不可用或生成失败。

**检查位置：** 打开 **设置 → AI 大模型**。

**处理方法：**

1. 确认目标 Adapter 的 Endpoint、模型和 API Key 已填写。
2. 文字创作需要勾选“支持文本”，并将该 Adapter 设为“文字默认 Adapter”。
3. 图片任务需要另行勾选“支持图片”，并设置“图片默认 Adapter”。
4. 点击“测试连接”；成功后再点击“保存 AI 配置”。

连接测试仍失败时，不要重复创建任务。先到模型服务商确认密钥状态、模型名称、账户额度和服务可用性。

## 信息源没有采集到内容

**你可能看到：** GitHub 仓库的“发布”标签一直显示“暂无发布记录”。

**检查位置：** 打开 **信息源 → GitHub → 订阅管理**，再选择目标仓库的“发布”标签。

**处理方法：**

1. 确认仓库地址是 `owner/repo` 或完整 GitHub URL。
2. 在 GitHub 网站确认仓库近期确实创建过 Release，而不只是提交或标签。
3. 在订阅管理中点击“同步”，或回到发布记录页面点击一次“刷新”。
4. 等待当前操作完成后再检查列表。

遇到访问频率限制时，等待限制恢复，或在 **设置 → GitHub API** 中配置可用令牌。不要连续刷新。

## 创作任务长时间没有完成

**你可能看到：** 任务长时间停留在“排队中”或“执行中”。

**检查位置：** 打开 **任务看板 → 任务日志**，找到目标任务并点击“查看日志”。

**处理方法：**

1. 查看“任务概览”中的当前步骤和开始时间。
2. 确认文字模型连接正常，发布账号仍处于启用状态。
3. 如果任务仍在执行，先等待，不要创建同名任务。
4. 确定不再需要该任务时，使用列表中的“取消”。

视频、图片和外部模型步骤通常比纯文字步骤耗时更长。只要状态仍在更新且没有失败错误，不应立即重试。

## 创作任务失败

**你可能看到：** 任务状态为“失败”，或者某个步骤显示错误文字。

**检查位置：** 打开失败任务的 **查看日志 → 任务概览**。

**处理方法：**

1. 找到失败步骤并阅读具体错误。
2. 按错误内容修正配置、账号状态或外部服务问题。
3. 失败步骤旁有“重试”时，只重试这一项。
4. 没有“重试”时，从原始内容重新创建任务。

> **注意：** 付费请求的结果是否送达不明确时，先到服务商侧确认调用记录。重试可能再次产生费用。

## 没有找到生成的草稿

**你可能看到：** 任务已经完成，但打开 **草稿箱** 后没有立即看到目标草稿。

**检查位置：** 先核对 **任务看板** 中的任务编号和状态，再打开 **草稿箱**。

**处理方法：**

1. 确认任务状态确实是“已完成”，而不是仍在执行或部分步骤失败。
2. 在草稿箱清除当前状态或写作模板筛选，回到包含全部相关草稿的列表。
3. 根据任务主题或创建时间寻找最新草稿。
4. 仍找不到时，回到任务日志检查最后一个步骤是否记录了保存失败。

不要因为列表筛选隐藏了草稿就重新创建任务；先确认原任务是否已经产生结果。

## 图片或素材不可用

**你可能看到：** 图片生成任务失败、上传失败，或者草稿中没有预期的封面和正文图片。

**检查位置：** 打开 **设置 → AI 大模型**、草稿的“素材”，以及 **创作 → 创作资产**。

**处理方法：**

1. 确认图片 Adapter 已勾选“支持图片”，并设为“图片默认 Adapter”。
2. 测试图片 Adapter 的连接，确认模型和返回格式符合服务要求。
3. 如果是上传文件，确认格式和文件大小适合当前入口。
4. 在草稿“素材”或“创作资产”中检查图片是否已经生成但尚未插入正文。

图片生成可能产生费用。先修正配置，再对失败步骤执行一次明确的重试。

## 发布账号不可选

**你可能看到：** “创建稿件”窗口中的发布账号列表为空，或手动创作提示“暂无启用账号”。

**检查位置：** 打开 **设置 → 发布账号**。

**处理方法：**

1. 确认至少有一个账号已经保存。
2. 确认账号显示“启用”；停用账号不会出现在创作任务的选择列表中。
3. 检查账号名称和平台是否正确，然后重新打开创建窗口。
4. 如果页面显示“发布账号加载失败”，先点击“重试加载发布账号”。

首次生成草稿不要求填写具体平台的发布凭据。只有执行真实发布时，才需要 AppID、AppSecret 或其他平台授权。

## 仍然无法解决问题

记录以下信息后再寻求协助：

- 出问题的页面和操作步骤；
- 任务编号和任务状态；
- “任务概览”中失败步骤的错误文字；
- 问题发生的大致时间；
- 是否能够稳定复现。

不要发送 API Key、Cookie、Token、完整账号凭据或包含敏感内容的截图。能够复现问题时，优先提供经过裁剪和脱敏的界面信息。
