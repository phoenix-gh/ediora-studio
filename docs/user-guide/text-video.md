# 制作文字视频

文字视频把一段口播稿转换为带配音、动态文字和分镜画面的 MP4 视频。本页按第一次制作成功所需的顺序说明操作。

## 完成后你将得到什么

完成整个流程后，你会得到：

- 一份可继续编辑的文字视频作品；
- 已确认的分段配音和完整时间轴；
- 可播放、可下载的 MP4 成片。

## 开始前的准备

开始前，请先完成以下准备：

1. 按照[首次使用设置](setup.md)配置 AI、语音合成和语音转写能力。
2. 准备一段适合朗读的中文口播稿。
3. 如需统一品牌样式，可先到“设置 → 文字视频”配置模板默认视觉；新项目会继承这些设置。

配音生成、时间轴生成和视频生成都需要等待处理。篇幅越长，通常耗时越久。

## 创建文字视频项目

1. 从左侧导航进入“文字视频”。
2. 点击“新建文字视频”。
3. 在编辑器顶部把“未命名文字视频”改成容易识别的作品名称。
4. 在“稿件与分镜”阶段输入口播内容。

作品会自动保存。列表中的“继续编辑”可让你稍后回到上次的制作阶段。

## 准备脚本

在“稿件与分镜”阶段，先把口播内容整理成最终版本，再处理分段。

1. 检查错字、标点和不适合朗读的链接、代码或特殊符号。
2. 需要精细控制时，把光标放到目标位置，点击“从此处分段”。
3. 也可以合并段落、调整顺序，或使用智能分段预览后再应用结果。
4. 确认内容后点击“进入配音设置”。

口播分段只决定配音如何生成，不等同于视频场景。视频分镜会在完整音频时间轴准备好后单独生成。

## 生成并确认配音

在“配音制作”阶段：

1. 检查右侧的语音模型、音色和语速等设置。
2. 点击“生成全部未生成段落”，也可以逐段点击“生成当前段”。
3. 每段生成后先试听；满意再点击“确认当前段”。
4. 不满意时点击“重新生成当前段”，试听新结果后再确认。
5. 多段内容全部确认后，点击“生成主音频”；单段内容确认后会直接复用该段音频并准备时间轴。
6. 等待页面显示时间轴已就绪，再进入“视频合成”。

修改已生成或已确认的文字，会使对应配音以及后续结果需要重新生成。部分语音服务会按调用计费，反复生成前请确认文本和参数。

## 调整画面与时间轴

进入“视频合成”后：

1. 点击“AI 生成分镜”，生成第一版画面场景。
2. 从左侧选择场景，在右侧检查展示文字、高亮词和动效。
3. 根据需要拆分、合并场景，或移动相邻场景的文字边界。
4. 要调整整体方向或当前场景，可使用“让 AI 调整画面”。
5. 选择视频模板，并通过“模板视觉设置”调整当前作品的外观。

高亮词必须实际出现在当前场景的展示文字中。修改主音频或时间轴后，如果页面提示分镜已失效，请先“重新校准分镜”。

## 预览和导出

1. 点击“预览全片”，检查文字、配音、节奏和场景切换。
2. 确认主音频、时间轴与分镜都已就绪后，点击“生成视频”。
3. 等待渲染进度完成。
4. 在成片预览中播放检查，点击“下载 MP4”保存文件。

如果生成成片后又修改了模板或画面，页面会提示当前播放的是上一版成片。点击“重新生成视频”后，下载的新文件才会包含最新修改。

## 当前能力边界

- 当前项目从文字视频页面新建，不能直接把草稿箱中的稿件一键转换为文字视频。
- 视频必须先完成配音确认、完整时间轴和分镜校准，才能生成 MP4。
- 智能分段不会替你确认配音；每段真实音频仍需试听和确认。
- 删除文字视频作品会删除项目记录，但不会同时删除已经上传到创作资产的文件。

## 常见问题

**“进入视频合成”后仍不能生成视频怎么办？**

回到“配音制作”，确认所有非空段落都已确认，并检查主音频和时间轴是否显示为就绪。若时间轴失败，使用页面提供的重新准备或重新对齐操作。

**分镜按钮提示重新校准是什么意思？**

说明主音频或时间轴已经变化，旧分镜不再与当前音频对应。重新校准后再预览和生成视频。

**修改后下载的仍是旧画面怎么办？**

看到“当前为上一版成片”提示时，先点击“重新生成视频”，等待完成后再下载。

更多失败处理方法见[常见问题与排查](troubleshooting.md)。
