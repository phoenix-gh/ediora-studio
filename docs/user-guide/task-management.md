# 查看和管理创作任务

创建稿件后，Ediora 会在后台分步骤完成内容处理。**任务看板**用于确认任务是否排队、正在执行、已经完成，或者需要人工处理失败步骤。

## 完成后你将得到什么

完成本章后，你将能够：

- 找到刚创建的创作任务；
- 判断任务当前所处状态；
- 查看任务概览和失败原因；
- 在必要时取消任务或安全地重试失败步骤。

## 打开任务看板

1. 从主导航打开 **任务看板**。
   页面顶部会显示今日运行、成功和失败等汇总信息，下方是创作规则和“任务日志”。

2. 在“任务日志”中找到目标任务。
   刚创建的任务通常排在前面，并显示任务标题、Job 编号、创建时间、任务类型和当前状态。

3. 如果任务较多，使用“任务类型”和“任务状态”筛选。
   从 GitHub 发布记录或手动入口创建的任务属于“手动任务”。选择筛选条件后，列表会只保留符合条件的任务。

> **提示：** 记下创建任务成功提示中的编号，可以更快地在任务日志中确认同一项任务。

## 理解任务状态

| 状态 | 你会看到什么 | 你可以做什么 |
| --- | --- | --- |
| 排队中 | 任务已经创建，但还没有开始执行 | 等待状态自动更新；确认模型配置可用即可 |
| 执行中 | 任务正在处理，并可能显示当前步骤 | 继续等待；需要停止时可以点击“取消” |
| 已完成 | 所有必需步骤已经结束 | 前往 **草稿箱** 查找生成结果 |
| 失败 | 任务或其中某一步显示错误 | 点击“查看日志”，阅读失败步骤和错误信息 |
| 已取消 | 任务已停止，不会继续后续步骤 | 如仍需内容，检查原因后重新创建任务 |

任务看板会定期刷新活动任务。状态没有立即变化时，先等待一小段时间，不要重复创建相同任务。

## 查看任务详情与日志

1. 在目标任务下点击“查看日志”。
   页面会打开“任务日志”窗口，并显示任务编号、标题和当前状态。

2. 打开“任务概览”。
   这里会显示创建、开始和结束时间，以及任务包含的执行步骤。

3. 查看每一步的状态和错误文字。
   如果某一步失败，错误会直接显示在该步骤下；允许重试的失败步骤旁会出现“重试”按钮。

普通使用者只需要“任务概览”就能判断任务结果。Agent 运行轨迹、AI 完整消息和执行事件属于开发者排查信息，在普通模式下不会显示，也不是完成创作所必需的内容。

## 取消任务

只有“排队中”或“执行中”的任务会显示“取消”。

1. 在目标任务下点击“取消”。
   系统会提交停止请求并刷新任务列表。

2. 等待状态变为“已取消”。
   状态更新后，该任务不会继续后续处理。

> **注意：** 取消只能阻止尚未完成的后续工作。外部服务如果已经接受某次付费请求，取消不一定能够撤回该次调用或费用。

## 安全地重试失败任务

1. 点击失败任务的“查看日志”，找到标记为“失败”的具体步骤。
   先阅读错误信息，不要在不知道原因时反复重试。

2. 处理可修正的原因。
   例如：回到 **设置 → AI 大模型** 修正模型配置，启用正确的发布账号，或等待暂时不可用的外部服务恢复。

3. 只有失败步骤旁显示“重试”时，才点击该按钮。
   系统会重新执行这个允许重试的步骤；不是所有失败步骤都支持原地重试。

4. 回到任务日志确认状态变化。
   重试被接受后，相关步骤会再次进入处理状态；完成后任务应更新为“已完成”，否则重新查看最新错误。

> **注意：** 重试可能再次调用模型、图片或视频服务并产生费用。网络中断、超时或“结果是否已经送达”不明确时，先到服务商侧确认调用记录，再决定是否重试。

## 常见问题

### 列表中找不到刚创建的任务

把“任务类型”和“任务状态”都改为“全部”，然后等待任务日志刷新。还可以根据创建成功提示中的任务编号核对。

### 任务长时间停留在“排队中”

先确认其他新任务是否也无法开始，并检查 **设置 → AI 大模型** 中的文字模型连接。不要通过重复创建同一任务来测试；这样只会产生多个相同的排队项。

### 失败步骤没有“重试”按钮

这表示该步骤不支持从当前位置安全重试。处理错误原因后，重新从原始内容创建一项新任务。

### 点击“取消”后状态没有立即变化

等待页面下一次状态刷新。不要连续点击；如果任务最终已经完成，以最新状态和实际产出为准。

## 下一步

任务显示“已完成”后，前往 **草稿箱** 查找生成结果。如果任务没有按预期运行，参阅[常见问题排查](troubleshooting.md)。
