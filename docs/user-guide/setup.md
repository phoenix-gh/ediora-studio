# 完成首次创作前的准备

在开始采集内容和创建草稿前，先完成一组最低配置。本章只处理首次创作必需的项目，高级模型参数、自动任务和具体平台发布可以以后再配置。

## 完成后你将得到什么

完成本章后，你将拥有：

- 一个可以正常生成文字的 AI 模型配置；
- 一个处于启用状态的发布账号；
- 一个可供创作任务使用的写作模板；
- 一个可以查看发布记录的 GitHub 跟踪仓库。

## 配置 AI 模型

1. 打开 **设置 → AI 大模型**。
   你会看到“LLM Adapter 实例”和“用途分配”区域。

2. 点击“添加 Adapter”。
   在弹窗中填写便于识别的 Adapter 名称、服务 Endpoint、模型和 API Key。

3. 勾选“支持文本”，然后点击“测试连接”。
   看到连接成功提示后，说明当前接口、模型和密钥可以配合使用。如果测试失败，先检查 Endpoint 是否包含服务要求的版本路径、模型名称是否存在，以及 API Key 是否有效。

4. 保存 Adapter，回到“用途分配”，把它选为“文字默认 Adapter”。
   如果没有单独的信息筛选模型，“信息筛选 Adapter”可以保留“跟随文字默认”。

5. 点击“保存 AI 配置”。
   保存完成后，刚才选择的 Adapter 会继续显示在“文字默认 Adapter”中。

> **提示：** 首次完成纯文字草稿不要求配置“图片默认 Adapter”。需要生成封面或正文配图时，再添加支持图片的 Adapter，并把它指定为“图片默认 Adapter”。

> **注意：** API Key 属于敏感信息。只在 Ediora 的设置页面中填写，不要把它粘贴到草稿、备注或截图中。

## 添加发布账号

发布账号代表你运营的内容账号。即使暂时不直接发布，创作任务也会使用账号画像来确定受众、语气和内容边界。

1. 打开 **设置 → 发布账号**，找到“账号画像”。
   页面会列出已有账号及其启用状态。

2. 点击“新增发布账号”。
   填写必填的“ID”和“名称”，并选择平台。ID 建议使用容易识别且长期稳定的英文标识，例如 `pub_tech`。

3. 至少补充“定位”“受众”和“调性”。
   “定位”用一句话说明账号面向谁、提供什么价值；“受众”和“调性”会帮助生成内容贴近账号需求。还可以按需填写选题方向、禁区和字数范围。

4. 保持“启用”处于开启状态，然后点击“保存”。
   保存后，该账号会出现在账号列表中，并显示“启用”标记。

> **提示：** 首次创作不需要填写公众号 AppID、AppSecret 或发布隧道。只有准备把内容直接存入公众号草稿箱时，才需要补充这些发布凭据。

## 创建一个写作模板

写作模板定义一类内容的固定写法。GitHub 发布记录的“创建稿件”流程会要求选择一个写作模板。

1. 从主导航打开 **创作 → 写作模板**。
   左侧会显示已有模板；如果列表为空，可以立即新建。

2. 点击页面左上区域的“+”按钮。
   页面会打开“新建写作模板”窗口。

3. 输入模板名称，并选择优先级，然后点击“创建”。
   首次使用可以创建一个名称明确的通用模板，例如“产品更新解读”。创建成功后，新模板会出现在左侧列表并自动打开。

4. 在模板内容区补充文章模式、标题公式、找素材的方法和禁区，然后点击“保存”。
   保存完成后，页面不再显示“未保存”，该模板就可以被创作任务选用。

> **提示：** 模板不必一次写得很复杂。先明确目标读者、文章结构和不应出现的内容，就足以支持第一次创作。

## 准备 GitHub 信息源

1. 从主导航打开 **信息源 → GitHub**。
   页面左侧显示“GitHub 雷达”、热门趋势和已跟踪仓库。

2. 点击“订阅管理”按钮，打开“订阅管理 · GitHub”。
   如果还没有仓库，页面会提示输入 `owner/repo` 或完整 GitHub URL。

3. 输入一个会持续发布 Releases 的仓库地址，然后点击“添加”。
   添加成功后，仓库会出现在“已订阅”和左侧“跟踪仓库”列表中，页面会进入该仓库的“发布”标签。

4. 如果暂时没有发布记录，点击“同步”或在发布记录页面点击“刷新”。
   同步启动后需要等待一段时间；看到一条或多条发布记录，才表示这个信息源已为首次创作准备好。

> **提示：** **设置 → GitHub API** 中的令牌是可选配置。公开仓库通常可以先不填写；遇到访问频率限制或需要访问受限资源时，再按实际情况配置。

## 检查准备是否完成

开始首次创作前，逐项确认：

- [ ] **设置 → AI 大模型** 中存在支持文本的 Adapter；
- [ ] “文字默认 Adapter”已经选择并保存；
- [ ] **设置 → 发布账号** 中至少有一个账号显示“启用”；
- [ ] **创作 → 写作模板** 中至少有一个可选模板；
- [ ] **信息源 → GitHub** 中至少有一个跟踪仓库；
- [ ] 该仓库的“发布”标签中可以看到发布记录。

## 常见问题

### 测试连接失败

重新检查 Endpoint、模型名称和 API Key。修改后再次点击“测试连接”；连接成功前不要继续创建任务。

### 已添加 Adapter，但无法选为文字默认

编辑该 Adapter，确认已经勾选“支持文本”并保存。只有声明支持文本的 Adapter 才会出现在“文字默认 Adapter”选项中。

### 创建任务时看不到发布账号

回到 **设置 → 发布账号**，确认账号已经保存且处于“启用”状态。停用账号不会出现在创作任务的账号选择列表中。

### GitHub 页面没有发布记录

确认选择的是会发布 Releases 的仓库，然后执行一次“同步”或“刷新”。如果仍然没有内容，可以换用一个近期确实发布过 Release 的公开仓库。

## 下一步

准备完成后，下一步是在 **信息源 → GitHub** 中采集并确认一条可用于创作的发布记录。
