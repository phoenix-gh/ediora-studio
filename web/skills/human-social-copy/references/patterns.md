# 内容结构模式

按素材选择一种主结构，不要把所有结构叠在一起。

## 工具或产品

读者场景 → 工具是什么 → 核心动作 → 适合谁 → 使用边界或下一步。

## 教程

可获得的结果 → 前置条件 → 最短步骤 → 容易出错的点 → 验证成功的方法。

## 观点或评论

明确判断 → 关键依据 → 影响对象 → 反例或限制 → 可讨论的问题。

## 新闻或发布

发生了什么 → 与读者的关系 → 最重要的变化 → 尚未确定的部分 → 一手来源。

## 个人复盘

真实背景 → 采取的动作 → 观察到的结果 → 改变了什么 → 可复用经验。没有真实经历就不要套此结构。

## 推荐清单

筛选标准 → 每项最适合的场景 → 明确差异 → 选择建议。避免只有名称和形容词。
