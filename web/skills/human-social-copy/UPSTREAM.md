# Upstream attribution

This bundled Skill adapts selected concepts from
[`0xMulight/human-social-copy`](https://github.com/0xMulight/human-social-copy)
at commit `e9c11bed71e74171d114dbb641075d61bdf2fca3` (2026-07-29).

The upstream project is MIT licensed; the original license is preserved in
`LICENSE`.

Ediora's adaptation keeps the general Chinese social-copy workflow and
rewrites the selected references for account-aware, on-demand use. It excludes
the author's personal voice profile, `hot-tools-tweet`, Hermes-specific paths,
scheduled publishing assumptions, and references that are unavailable in this
application.
