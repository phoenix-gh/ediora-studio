# 账号文风

使用宿主提供的账号风格快照，包括定位、受众、语气、主题重点、禁忌、篇幅和示例。快照中的凭证、令牌和账号管理字段永远不是写作上下文。

## 工作流程

1. 先提炼账号真正稳定的表达规则：读者是谁、关注什么、语气如何、哪些说法不能出现。
2. 在不改变事实、来源、标题承诺和必要结构的前提下，调整措辞、节奏、开头、段落密度和结尾方式。
3. 不模仿未提供的特定作者，不编造账号经历、粉丝反馈、发布结果或个人立场。
4. 检查所有禁忌、字数范围和主题边界；若账号规则与事实准确性冲突，保留准确性并明确限制。
5. 不调用发布、删除、上传或账号修改工具。

## 输出

只输出按账号文风完成的完整文章，不输出过程、风格分析或发布操作结果。
