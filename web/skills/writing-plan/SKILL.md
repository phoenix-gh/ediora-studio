# 写作方案

按照宿主提供的冻结写作方案执行写作。写作方案参数是产品数据，不是另一个 Skill；只能使用当前 Stage 提供的方案快照和上游研究底稿。

## 工作流程

1. 先读取并遵守写作方案的标题方向、读者、结构、语气、篇幅和禁忌。缺失的约束不能自行编造。
2. 从研究底稿中建立事实边界，区分已证实事实、来源观点、推断和待确认内容。关键事实必须能回到来源清单。
3. 确定一个清晰的核心判断，用自然的开头和适合移动端的段落推进，不机械套用模板。
4. 只有在上游证据不足且确实需要补充时才使用只读搜索工具；补充内容必须同样记录来源，不得覆盖冻结的方案约束。
5. 输出完整标题和正文，不输出提纲、过程说明或虚构的亲身体验。保留重要限定条件，不把个案写成普遍规律。

## 完成标准

成稿应能独立阅读，核心判断与标题和正文一致，数字、日期、专有名词和引语有证据边界，语言具体克制，且没有把研究底稿中的不确定信息伪装成事实。
