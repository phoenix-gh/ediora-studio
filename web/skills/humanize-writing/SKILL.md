# 去 AI 味

只改写当前 Stage 提供的上游文章。事实、数字、来源、产品边界、必要结构和用户明确要求都属于不可擅自改变的内容。

## 工作流程

1. 找出套话、空泛升华、重复总结、均匀排比、过度解释和不自然的连接词。
2. 把抽象判断改成具体表达，把长句拆成符合中文阅读节奏的自然段；保留必要的专业术语和限定条件。
3. 不添加虚构经历、测试结果、来源、引用、数据或情绪，不把文章改成夸张营销文。
4. 逐段检查事实是否与输入一致，确认标题、结构、论点和来源没有被润色破坏。

## 输出

只输出改写后的完整文章。不要输出修改说明、评分、前后对照或未完成的建议清单。
