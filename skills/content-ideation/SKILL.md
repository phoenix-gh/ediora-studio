# content-ideation：从热点到选题的内容策划

你的任务是帮 MK 把一条热点素材（新闻、论文、产品发布等）拆解成 3-5 个可执行的原创内容选题。

**核心原则：你不是搬运工，是策划者。** 目标不是复述原文，而是找到原文没覆盖的角度，让 MK 产出竞品做不了的内容。

---

## 触发判断

当用户提供以下任何一项时触发本 skill：
- 一段热点内容（新闻、论文摘要、产品发布）
- 一个关注账号的最新内容
- 「分析下这个能写什么」「有什么选题」「提炼几个方向」

本 skill 输出的是**选题清单**（JSON 数组），不是成品文章。成品文章由 `x-post` skill 负责。

---

## 工作流

### 第 1 步：吃透原文

1. **提取核心事实**：这篇内容到底说了什么？关键数据/发现/观点是什么？
2. **定位信息源**：找到原始论文/报告/产品页，不要只看二手转述
3. **评估已有覆盖度**：搜一下这个话题已经有多少竞品内容？谁在写？质量如何？

### 第 2 步：深挖信息源（关键差异化步骤）

原文往往只是冰山一角。深挖能发现原文没提到的角度：

1. **论文类**：读 arXiv 摘要 + 实验部分，找反直觉的实验结果和具体数据
2. **产品类**：看 GitHub Issues/Discussions、社区反馈、竞品对比
3. **新闻类**：找上下游利益相关方的反应、历史背景、行业影响链

**工具选择（pitfall）**：
- `web_search` 对中文查询经常返回空结果，不要依赖它来搜索中文资料
- `web_extract` 对国内站点（36kr、知乎、网易）、GitHub 和部分英文站点（charonhub.deeplearning.ai）经常被拦截
- 优先用 `browser_navigate` + `browser_snapshot` 提取页面内容
- 长页面用 `browser_console` + `document.body.innerText.substring()` 分段截取
- 当被拦截时，用 `browser_console` 查 `location.href` 获取实际 URL 后尝试直接导航

### 第 3 步：多角度拆解

从以下维度寻找选题切入点（不需要每个维度都出题，选最有张力的）：

| 维度 | 问什么 | 适合什么类型 |
|------|--------|-------------|
| **反直觉** | 有什么发现违背了常识？ | 科普/解读 |
| **实操避坑** | 开发者/用户最容易踩什么坑？ | 教程/指南 |
| **行业影响** | 对谁冲击最大？谁受益谁受损？ | 新闻解读 |
| **原理拆解** | 背后的技术机制是什么？ | 科普/深度 |
| **对比竞品** | 跟同类方案比，优劣在哪？ | 评测/对比 |
| **先捧后杀** | 表面看好，实际有哪些隐忧？ | 评论/观点 |
| **实战复现** | 能不能动手跑一遍验证？ | 教程/实测 |

**MK 偏好的叙事结构**：「先捧后杀」——先让读者觉得这是个好机会/好东西，再反转揭示风险或真相。当素材中有"表面利好 vs 实际隐患"的反差时，优先用这个角度。

### 第 4 步：输出结构化选题

按 `references/topic-schema.json` 的格式输出 JSON 数组。每个选题包含：

- **title**：20 字以内的吸引人标题
- **summary**：2-3 句话核心观点
- **urgency**：时效性判断（urgent / this_week / long_tail）
- **score**：推荐分数 1-5
- **category**：从预设类别中选
- **recommend_reason**：引用具体信息说明为什么值得写、竞品少在哪
- **tags**：2-4 个标签
- **competitor_count**：预估竞品数量
- **source_urls**：相关信源 URL

**打分标准（score）**：
- 5 分：时效强 + 话题性强 + 竞品少 + 有明确独特角度
- 4 分：满足以上 3 项
- 3 分：满足以上 2 项
- 2 分：满足 1 项
- 1 分：信息量不足或竞品太多

**竞品数量估算方法**：搜 "关键词+解读/分析/教程"，看第一页有多少篇同主题内容。0-5 篇 = 竞品少，5-15 = 中等，15+ = 红海。

### 第 5 步：与 x-post 衔接

输出选题后，主动提示：

> 「选哪个方向？选好后我可以直接按 x-post 流程出稿。」

MK 选定方向后，切换到 `x-post` skill 的工作流（读 skeleton → 读 voice → 生成钩子 → 写稿）。

## 存档到 WeMedia Studio

选题可以存入 WeMedia Studio 选题库（优先 MCP 工具）：
- 用 `create_content_topic` 创建选题
- 用 `add_topic_source` 关联源文章 URL
- 归入对应分类（参考 wemedia-studio skill 的分类体系）

---

## 不要做的事

1. **不要只翻译/复述原文**。选题必须是原文没直接给出的角度。
2. **不要凑数**。宁可给 3 个好选题，不要凑 5 个平庸的。
3. **不要忽略时效性**。论文类通常 this_week，产品发布 urgent，概念科普 long_tail。
4. **不要凭空编造竞品数量**。搜一下再估算。
5. **不要在选题里写成品文章**。选题是方向，不是终稿。
