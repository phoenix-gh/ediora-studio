# hook-principles.md：钩子原理

**钩子（hook）= 让人停下滑动的开头机制。**

骨架里的"钩子词"是钩子的最小单位；这里讲的是**整段开头的机制**——比钩子词更高一层。

---

## 钩子的底层心理机制

人会停下滑动，是因为开头触发了以下之一：

### 1. 反差/反直觉
读者预期 A，你说 B。预期落空 = 注意力被勾住。

```
"侧边栏会话有很多诟病，但用户已经习惯了。"
（预期：要批评侧边栏；实际：要分析用户为什么习惯了。落差。）
```

### 2. 具体张力
具体的人、具体的数字、具体的时间，让事件"真"起来。

```
"Hashimoto 是 GitHub 的第 1299 号用户，2008 年注册，用了 18 年。"
（具体到不能再具体，读者立刻进入故事。）
```

### 3. 痛点共鸣
读者心里有的痛点，你替他说出来。

```
"做强化学习的说的是 Dreamer，做视频生成的说的是 Sora，大家各说各的，论文之间根本没法比。"
（读跨领域综述的人都知道这个痛，这一句立刻俘获共鸣。）
```

### 4. 揭秘/好奇
暗示后面有秘密、有内幕、有未公开的东西。

```
"OpenAI 发了一篇技术博客，认真调查了一个荒诞的问题：为什么他们的模型越来越爱说哥布林？"
（"荒诞"+"为什么" = 揭秘机制启动。）
```

### 5. 立场宣示
直接亮明态度。**有立场比中立更抓人**，因为读者会条件反射地"赞同"或"反驳"。

```
"试用下来 CodexPotter 不错，推荐下。"
（开头就表态，读者立刻有态度——要么继续看推荐理由，要么准备反驳。）
```

## 单条帖子 vs Thread 的钩子差异

### 单条帖子
钩子在第一句。一句话定生死。

### Thread（多条串联）
钩子在**第一条整条**，不只是第一句。第一条要：
- 标明这是 thread（"开个 thread 讲讲 X"，或者用 "🧵" 但宝玉骨架里不用 emoji，所以推荐用文字标明）
- 给出整个 thread 的"承诺"（看完能得到什么）
- 留一个明确的"下一条"指向

```
（thread 第一条示意）
最近发现一个反直觉的事情：很多人觉得 [X]，但实际上 [Y]。

为什么会这样？我研究了几天，整理出 4 个原因，也整理了对应的破解方法。

下面一条一条说。
```

## 写钩子的实操方法：三选一

每次写帖子，**强制生成 3 个不同方向的钩子**给 MK 挑：

### 方向 A：事实型（保守）
直接陈述事件 + 一个钩子词。

```
"OpenAI 发了一篇技术博客，认真调查了一个荒诞的问题。"
```

适合：内容本身已经够吸引人，不需要靠开头放大。

### 方向 B：判断型（中等）
开头就亮观点。

```
"哥布林这事，揭示了 RLHF 的一个根本问题。"
```

适合：你对内容有明确观点，且观点本身有讨论价值。

### 方向 C：悬念型（激进）
开头制造问号或反差。

```
"为什么 ChatGPT 越来越爱说哥布林？这个问题比你想的有意思。"
```

适合：内容需要靠开头放大，或者你想引发讨论。

**给 MK 时的格式：**

```
钩子 A（事实型）：[钩子句]
钩子 B（判断型）：[钩子句]
钩子 C（悬念型）：[钩子句]

我推荐 [X]，因为 [理由]。你想用哪个？
```

## 最常见的钩子失败模式

❌ **空泛形容词**："一个超棒的工具"、"非常厉害的发现"
→ 改：换成具体数字或具体动作

❌ **铺垫太长**：第一句还在交代背景
→ 改：把"是什么"压缩到一句话内

❌ **过度营销**：感叹号、🚀、"重磅"
→ 改：去掉所有感叹号和 emoji，让事实自己说话

❌ **泛指主语**："最近 AI 圈"、"很多人都在说"
→ 改：用具体的人/公司/事件做主语
