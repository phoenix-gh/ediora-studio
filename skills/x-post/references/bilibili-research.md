# B站竞品账号研究指南

用于分析B站AI/科技领域对标账号，提取选题规律和爆款公式。

## 搜索与数据获取

### 搜索排序
- B站搜索 URL: `https://search.bilibili.com/all?keyword=XXX&order=click`
- `order=click` 按播放量排序，直接看爆款
- `order=pubdate` 按发布时间排序，看最新动态
- 未登录状态下可正常搜索和查看视频列表

### 数据提取要点
从搜索结果 snapshot 中可提取：
- 视频标题
- 播放量（如 "550.2万"）
- 弹幕数
- 视频时长
- 发布日期
- UP主名称

### 账号页面
- 空间页: `https://space.bilibili.com/UID/video`
- 未登录时视频列表可能不加载（JS渲染问题）
- 备选：通过搜索页按UP主名搜索，用 `order=click` 排序

## 分析框架

### 1. 爆款标题公式提取
观察 TOP10 视频标题的共性模式：
- 反问句式："你管这破玩意叫XX？"
- 悬念式："为什么XX？底层原理揭秘"
- 数据式："全网最细！XX从原理到代码"
- 情绪式："最担心的事儿可能要发生了"

### 2. 选题方向分类
- 原理解释型：拆解技术底层逻辑
- 热点解读型：紧跟新模型/论文/产品发布
- 工具实测型：评测AI产品使用体验
- 科学叙事型：用故事包装科学史（大圆镜路线）
- 自嘲/人格化：创作者自身的成长故事

### 3. 内容结构分析
- 时长分布：爆款集中在哪个时长区间？
- 更新频率：周更/日更/不定期
- 系列化程度：是否有合集/系列

### 4. 粉丝互动特征
- 弹幕数 vs 播放量比值（互动率）
- 评论区常见讨论话题

## 已知对标账号（AI领域，2025-2026数据）

### 飞天闪客（42万粉）
- 定位：技术翻译，"专治不明白"
- 爆款：《为啥所有AI都数不清手指？》550万播放
- 标题特色："你管这破玩意叫XX？"系列
- 策略：紧跟热点 + 底层原理拆解 + 人格化内容
- B站+YouTube+抖音三平台运营

### 大圆镜科普（全网170万粉）
- 定位：AI视觉+科学史叙事
- 爆款：《免疫系统：当守护者成为毁灭者》909万播放
- 全AI工作流：Midjourney生图 → 可灵视频 → 剪辑
- 半年涨粉200万，总播放3.5亿
- 时长统一6-8分钟，节奏紧凑

### 懂点AI事儿（技术教学向）
- 定位：AI原理+代码实现
- 爆款：《全网最细！DeepSeekMoE》2.6万播放
- 播放量天花板较低（太硬核限制传播）
- 紧跟论文热点，第一时间出解读

## 对MK内容策略的启示

MK的定位（AI前沿翻译+产品洞察，对标@dotey）适合走"飞天闪客+懂点AI事儿"的结合路线：
- 选题用问题切入法（"为什么ChatGPT会胡说八道？"）
- 内容深度用原理+实操
- 更新节奏周1-2更，紧跟热点
- 标题用反问/悬念/数据式
- 避免大圆镜的重制作路线（需要大量AI视觉能力）
