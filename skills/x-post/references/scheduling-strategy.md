# X 发帖排期与新号运营策略

## 新号养号节奏（必须遵守）

新号处于「低权重 + 高风控」状态，高频发帖会触发限流甚至封号。

| 阶段 | 时间 | 每日发帖 | 同时做 |
|------|------|---------|--------|
| 🟢 冷启动 | 第 1-3 天 | **0 条**（只看不发） | 浏览、点赞 5-10/天、关注 5-10/天 |
| 🟡 轻度运营 | 第 4-7 天 | **1-2 条** | 点赞 10-20、少量评论 |
| 🟠 过渡期 | 第 8-15 天 | **2-3 条** | 参与热门话题、增加互动 |
| 🔵 正常运营 | 15 天后 | **3-5 条** | 稳定输出 |

**新号禁忌：**
- 一上来就高频发推 → 限流
- 固定时间固定格式发 → 标记为 bot
- 使用自动 follow/unfollow 工具 → 封号（X 最严规则）
- 自动点赞/转推工具 → 封号
- 自动 DM → 封号
- 多账号发相同内容 → 封号

## X API 发帖限制（2026 年）

| API 等级 | 每日发帖上限 |
|---------|------------|
| 免费版 | ~17 条/天 |
| Basic ($100/月) | ~100 条/天 |
| Pro ($5000/月) | ~300 条/天 |

- 重复内容 24-48 小时内会被拒绝（error code 187）
- 用官方 API（xurl）发帖 = X 明确允许
- 定时发布 = 完全合规

## X 自动化规则（红线）

**明确允许 ✅：**
- 定时发布原创内容
- 通过 OAuth 授权的 App 发帖
- 自动分享自己的内容（博客、GitHub 等）
- API 发帖（在 rate limit 内）
- Bot 账号（需标注）

**明确禁止 ❌：**
- 自动 follow/unfollow（最严规则）
- 自动点赞/转推/收藏
- 多账号发相同内容
- 自动 DM
- 未授权爬取
- 重复发同一链接
- 未请求的 @mention

## 工作流：内容生成 → 人工发布

MK 偏好手动发布，不使用自动发布。流程：

1. 每天定时（如 8:00 AM）生成当日草稿（1-3 条）
2. 推送到 Telegram 供 MK 审阅
3. MK 选择要发的，手动复制发布
4. 可选：MK 反馈修改意见，重新生成

**养号期（前 2 周）**：每天只生成 1-2 条，MK 选 1 条发
**稳定期（2 周后）**：每天生成 2-3 条，MK 选发
